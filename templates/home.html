About This Page

Simple way to quickly timestamp the files in your zip folder and orgainizes them by date.

Example: Convert 'picture.jpg' to '2025_06_07_00_00_00_picture.jpg'




Upload a ZIP Folder (.7z or .zip)






    How to get a zipfile: File Compression Tips


    How it works



    The date and time of creation will be extracted from JPG, JPEG, PNG and MP4 files. Future development includes expanding to more files types.

    If the files is not of the types listed above, then the timestamp will be taken from the last time the file was modified in your filesystem.


    Note: It is prefered to upload a .7z zipfile since this format retain file datetime information from your file system.
