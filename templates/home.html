    How it works


    The date and time of creation will be extracted from JPG, JPEG, PNG and MP4 files by pulling out EXIF and metadata from each photo.

    This is the best way to organize photos that need a naming convention.

    If the files is not of the types listed above, then the timestamp will be taken from the last time the file was modified in your filesystem.

    This will ensure chronological file naming in file system for easy file tracking.




    Why this format?


    The best naming convention for your files is to timestamp your files with the prefix "year_month_day_hour_minutes_second".

    This file naming system places all your files chronologically in your file system.
