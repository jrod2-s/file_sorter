File Compression Tips

Here is a simple guide to compressing your files to upload them to the website.

Note: I highly recommend that you follow the instruction to compress your folder to .7z format to retain all file system date time information.

Compress to .7z or .zip on Windows 11

1. Open up 'File Explorer' and find the folder with all the files that need to be timestamped. The website will not stamp nested folders so keep all the files in the first level of the folder.

2. Right click the folder of that will be converted and look for the option that says 'Compress To' and click on it.

3. Click on compression format that you want to use (.7z or .zip)

Warning: If you choose to upload a zip file instead of a .7z file, all of your timestamps will be made for the current date time if the information is not found within the file. Use .7z compression
